# eMMC Expansion Board

This subdirectory contains the kicad files for the eMMC expansion board. I will be using kicad 9 for compatibility with the debian repos.

The eMMC chip we will be using is the KLM8G1GETF-B041 from Samsung. The documentation on regulator capacitors is minimal, so I used 2.2uF since that was the standard among other chips.
